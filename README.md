# Global Water Stress Prediction 🌍

## About the Project
Global Water Stress Prediction is a machine learning project that analyzes freshwater stress across different countries using official data from the Food and Agriculture Organization (FAO), based on UN Sustainable Development Goal (SDG) Indicator 6.4.2.

The project aims to explore historical water-stress trends, compare countries, visualize data, and develop machine learning models to estimate water-stress values.

## Objectives
- Analyze global water-stress data.
- Identify countries experiencing high water stress.
- Explore historical trends.
- Perform data cleaning and preprocessing.
- Create meaningful data visualizations.
- Develop machine learning models for experimental prediction.

## Dataset
**Source:** FAO – SDG Indicator 6.4.2 (Level of Water Stress)

[FAO Water Stress Dataset](https://www.fao.org/sustainable-development-goals-data-portal/data/indicators/642-water-stress/)

The dataset contains geographical and water-stress observations from different areas and time periods.
